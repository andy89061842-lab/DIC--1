## ✨ 功能介紹

### 👤 個人簡介（Profile）
- 顯示姓名、Avatar 頭像、科系 / 專業
- 簡短自我介紹與狀態徽章
- 「查看作品」與「聯絡我」快速按鈕

### 🔧 技能展示（Skills）
- 列出多項技能，包含 Python、C/C++、JavaScript、Machine Learning、AI、IoT、Web Development、Data Analysis
- 每項技能附有進度條動畫
- 支援「Languages / Frameworks / Tools & AI」分類篩選

### 🚀 作品集（Projects）
- 卡片式作品介紹，包含：
  - 作品名稱與描述
  - 使用技術標籤
  - GitHub 連結 & Live Demo 連結
- 懸停時呈現動態發光邊框效果

### 🕐 即時時鐘（Live Clock）
- **數字時鐘**：顯示 時:分:秒 及完整日期
- **類比時鐘**：SVG 時針、分針、秒針即時轉動
- 自動對齊 **台灣標準時間（UTC+8）**
- 每秒自動更新，無需重整頁面

### 📬 聯絡資訊（Contact）
- Email、GitHub、LinkedIn 快速連結卡片
